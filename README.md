# Student Performance Predictor

A Machine Learning project that predicts student performance using academic and behavioral factors.

## 📌 Project Overview

This project uses Machine Learning algorithms to analyze student data and predict their performance.

The project includes:
- Data loading and exploration
- Data preprocessing
- Linear Regression
- Random Forest Regression
- Model evaluation
- Student performance prediction
- Feature importance visualization
- Actual vs Predicted visualization

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🤖 Machine Learning Models

### Linear Regression
Used as a basic regression model for predicting student performance.

### Random Forest Regression
Used to improve prediction performance and identify the most important features affecting student performance.
